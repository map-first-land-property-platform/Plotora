# Plotora — Map-First Land and Property Platform

**Discover property by location. Explore land with confidence.**

Plotora is a modern, web-based land and property discovery and management platform designed to improve how people **search for, advertise, evaluate, and manage real estate in Sri Lanka**.

Unlike traditional real estate websites that primarily rely on photographs and text-based listings, Plotora follows a **map-first approach**. An interactive map serves as the starting point for property discovery, helping users understand *where* a property is located before exploring its details.

The platform aims to connect **buyers, renters, property owners, sellers, real estate agents, developers, and administrators** in a transparent, efficient, and user-friendly digital real estate ecosystem.

> **Project status:** Initial development / repository setup. The capabilities described below represent the planned product scope and will be delivered progressively.

## Project Overview

Property discovery in Sri Lanka can be challenging because information is spread across multiple sources, location details are inconsistent, and buyers often lack the geographical context needed to assess a property.

Plotora aims to address these problems by bringing together:

- Interactive maps and geographic information systems (GIS)
- Structured property listings and management
- Advanced, location-aware search and filtering
- Land boundary visualization
- Location intelligence and nearby amenities
- Communication and inquiry management
- Role-based portals and platform administration

Buyers and renters will be able to discover properties in their preferred areas, inspect available land boundaries, explore nearby facilities, and compare options. Sellers, owners, agents, and developers will be able to create and manage listings, provide property-specific details, and respond to potential customers.

## Planned Key Features

| Feature | Description |
| --- | --- |
| **Map-first property discovery** | Browse land, houses, apartments, and commercial properties on an interactive map with markers and clustering. |
| **Land boundary visualization** | Draw and display land boundaries using polygon-based mapping tools. |
| **Advanced search and filters** | Filter by location, price, property type, land extent, availability, and relevant property-specific attributes. |
| **Property listing management** | Create, edit, submit, publish, and manage property listings with appropriate details and photographs. |
| **Location intelligence** | Explore available data about roads, nearby facilities, accessibility, elevation, and relevant environmental or hazard factors. |
| **Role-based experiences** | Provide interfaces and permissions appropriate to different types of users. |
| **Agency and developer tools** | Manage multiple listings, portfolios, projects, and customer inquiries. |
| **Property inquiries** | Enable interested users to contact property representatives. |
| **Administration and moderation** | Support listing review, user management, moderation, and verification workflows. |
| **Responsive website** | Make the platform usable on desktop, tablet, and mobile browsers. |

*The availability and accuracy of geographic or environmental insights will depend on the data sources integrated into the platform.*

## User Roles

- **Buyer / Renter:** Explore properties, apply filters, review listings, and send inquiries.
- **Property Owner / Seller:** Create and manage listings, define land boundaries, and respond to inquiries.
- **Real Estate Agent / Agency:** Manage listings and property portfolios on behalf of clients.
- **Property Developer:** Showcase developments, projects, and available properties.
- **Platform Administrator:** Manage users, review listings, and oversee platform operations.

## Project Objectives

The primary objective of Plotora is to build a **scalable, secure, and user-friendly** real estate platform that improves property discovery and management in Sri Lanka.

More specifically, the project seeks to:

1. Make location the central part of the property-search experience.
2. Improve the accessibility, structure, and clarity of property information.
3. Support better-informed decisions with geographic context and available location insights.
4. Simplify listing management for owners, agents, and developers.
5. Improve communication between property seekers and representatives.
6. Deliver a consistent, intuitive experience for different user roles.

## Development Approach

Plotora is being built as a full-stack **web application** using collaborative development, version control, modular design, and iterative testing.

The project is planned around **six progressively enhanced MVP releases**. Each iteration will extend the previous version with additional capabilities, refinements, and quality improvements. The development goal is a feature-complete, responsive web platform; a native mobile application is considered a possible future enhancement rather than part of the initial delivery.

## Collaboration and Git Workflow

The project uses a shared GitHub repository and a branch-based contribution workflow:

- `main` — stable, reviewed releases
- `develop` — integration branch for ongoing development
- `feature/*` — individual feature branches

Changes should be submitted through pull requests, reviewed, and tested before merging into `develop`. Validated sprint releases can then be promoted to `main`.
